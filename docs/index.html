Space Syntax 조건 입력

한 줄에 조건 하나. 대상.지표 연산자 목표값 [.. 최악값] [w=가중치]
대상은 실 키 또는 전역을 뜻하는 @. #으로 시작하면 주석.

연산자
<= 작을수록 좋음 · >= 클수록 좋음 · == 목표값 ±허용치
예시
hall.step_depth <= 1 w=2 — 현관 깊이 1이면 만점
living.integration_rank <= 1 .. 5 w=2 — 순위 1위 만점, 5위 0점
master.step_depth == 3 ± 1 w=2 — 깊이 3 목표, ±1 허용
@intelligibility >= 0.9 w=1 — 명료성이 높을수록
@disconnected_rooms <= 0 w=2.5 — 고립된 실 없어야
